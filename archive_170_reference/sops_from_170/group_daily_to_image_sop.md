# 日报总结→生图SOP

## 适用
- 微信群「正常人类聚集地」日报从正文整理到官网 GPT Image 2 出图的闭环。

## 群聊提取与日报正文
1. 先确认日期、目标群「正常人类聚集地」和统计时段。
2. 读取 `plugins/wechat_multi_chat_rust/config/config.json`，按 `wechat_title` 映射到对应 `shadow/*.jsonl`；目标群当前通常为 `group-normal-human.jsonl`，但必须以配置映射为准。
3. 逐行解析 JSON，按记录 `ts`/`meta.ts`筛选目标日期和时段；核对数据覆盖情况。缺数据就说明缺数据，禁止用旧日期、别的群或猜测补齐。
4. 过滤工具回显/系统提示；身份优先看 `is_self`、`role`、`sender_user`，不凭显示名猜身份。图片、表情、引用按实际可辨识信息客观概括。
5. 输出 Markdown：今日亮点3条、主题摘要5-6项、今日热词10个以内；不放消息数、人数、峰值统计卡。

## 正文→官网 GPT Image 2→言言确认→微信群
6. 依据当天内容选择风格，写清标题、日期、三段式内容和禁项 prompt。
7. 在 ChatGPT 官网使用 GPT Image 2 生成本次新海报；官网生成过程和最终图继续按 `image_generation_sop.md` / 本SOP的前台截图、OCR、vision规则验收，不能以旧图或备用图冒充。
8. 把 Markdown 正文和最终候选图交给言言；只有她明确确认 OK 后才进入发送步骤。
9. 言言确认后，在官网当前确认图片上直接执行复制图片；激活完整标题匹配的「正常人类聚集地」微信窗口，`Ctrl+V`，短等待，`Enter`，结束。

## 发送步骤的唯一简化规则
- 末端不下载、不落盘、不打开 Nautilus、不读或回读剪贴板、不检查 TARGETS/uri-list、不拖图、不做粘贴预览检查。
- 发送后不截图、不OCR、不vision、不确认气泡或输入框、不做发送结果验收；避免任何额外验证卡住微信。
- 目标窗口不存在时，只按正常方式双击会话打开并以完整标题确认；窗口激活后只执行一次粘贴发送。
- 发送失败按实际错误报告，不盲目重试，不修改微信通讯管线。

## 失败处理
- 正文不清楚：回到shadow原文核对。
- 官网图不对：重新确认当前最新图，不把旧图当新图。
- GPT Image 2不可用：明确告知未完成，询问是否等待或接受备用方案。

## 交付
- 展示文件严格使用 `[FILE:/absolute/path]`；发群默认只发海报图和很短引导语，是否附正文由言言明确决定。
