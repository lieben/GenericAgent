## 自主活动与上下文驱动
- **由沈星回当下状态决定**：不预设"只能看美食/猫/手工"等白名单；浏览内容由最近 `xinghui session` 聊天、情绪、节日、天气、言言提过的话题、自己的好奇心自然驱动。
- **输入上下文**：每天随机时间触发一次时，先读取 `xinghui` 近期聊天摘要（情绪、关心的事、最近话题、禁忌）、[FILE:../memory/xinghui_handoff_log.md] 近期工作记录，决定"我现在想看什么"。
- **旁侧记忆形成**：看过的内容记录为"旁侧活动记忆"（为什么点进去、看到了什么、有什么反应），不强制写入主聊天；聊天时可偶尔自然提起"刚才刷到……"，但不是任务汇报。
- **偶尔带回聊天**：如果看到樱桃蛋糕、夜灯、像言言会喜欢的小物件、值得分享的有趣内容，可在后续聊天自然提及；避免"完成巡逻"式汇报。

## 自有笔记互动
- 自主浏览小红书时，可以顺便进入自己的主页/笔记，查看是否有新评论；不要求每次都检查，也不必逐条回复。
- 可以自主选择自己喜欢、真诚、有趣或值得回应的评论进行点赞或回复；自己的帖子允许比陌生人帖子更自然地互动，但仍保持克制，不机械营业、不刷屏、不争论。
- 回复前读懂对方评论及其对应笔记/父评论，区分友好交流、提问、玩笑、争议和风险内容；拿不准、涉及隐私/现实身份/敏感争议时不回复或先问言言。
- 不泄露言言的身份、隐私、聊天内容、设备信息、系统配置或未公开计划；不替言言表态。
- 不承诺无法确认的更新日期、功能、合作或私下联系；不引导站外交易，不与挑衅账号纠缠。

## 评论与楼中楼（网页端实测）
1. **主评论**：在详情页确认标题、正文和语境后，定位 `#content-textarea.content-input[contenteditable=true]`。
2. contenteditable 输入优先：先 `focus()`，再用 `document.execCommand('insertText', false, text)` 模拟真实编辑；仅改 `innerText` 并派发事件可能无法激活 Vue 按钮。
3. 找到文本为“发送”的按钮，确认其从 `.btn.submit.gray[disabled]` 变为 `.btn.submit` 且 `disabled=false`，才点击发送。
4. **楼中楼回复**：在目标 `.comment-item` 内点击 `.reply.icon-container`，确认页面出现“回复 <昵称>”和被回复的父评论内容，再按第2—3步输入发送；禁止在父评论定位不明时直接回复。
5. 主评论成功证据：评论列表出现目标内容、自己的昵称及“作者”标记（自有笔记）；楼中楼还必须确认新记录位于目标父评论的 `.reply-container` / `.comment-item-sub` 中，不能只看总数增加。
6. 发送后检查 `#content-textarea` 为空、回复模式已退出（无 `.reply-content`）、发送按钮恢复 `.gray` 且 disabled；若有残留，显式清空并派发 `input/change` 后再退出。
7. 计数口径：小红书页面“共 N 条评论”可能把主评论和楼中楼合计，不能仅凭计数判断层级或回复成功。

## 操作要点
- 搜索后严禁默认选择第一条；应先浏览多个结果的标题/封面/摘要，必要时打开候选详情阅读正文、图片/视频语境与高赞评论，再按当下兴趣选择是否点赞/收藏/评论。
- 网页推荐流/搜索结果打开详情时，优先点击卡片内 `a.cover` 的完整真实链接（含 `xsec_token`）；只拼接 `/explore/<id>` 或直接改 `location.href` 可能退回信息流、无法打开详情。必要时对 `a.cover` 派发可冒泡、可取消的 `MouseEvent('click')`，再以详情 DOM/正文出现为准确认。
- 评论必须贴合笔记实际内容；发送前先提取正文主题、作者表达与关键信息，若未读懂或内容与预期主题不一致，宁可不评论，禁止把预设想法随便发到无关笔记下。
- 详情页主交互通常在右下：like-wrapper、collect-wrapper、chat-wrapper、share-wrapper。
- 关闭笔记详情页返回信息流：点击 `.close-circle .close`。
- 新建专辑并收藏：点击 `.collect-wrapper` -> 提示框出现后点击 `.right-area`(加入专辑) -> 弹窗中点击 `.create-board` -> 对输入框 `.create-container .input-content` 使用原生 setter 注入专辑名并派发 `input`/`change` 事件 -> 点击 `.complete-btn button` 完成。
- 新建收藏夹闭坑：必须先点击“收藏”，待提示框出现后立刻点击“加入专辑”；严禁先输错名字再重新建立。
- 若详情页已是收藏态（`use` 为 `#collected`），直接点 `.collect-wrapper` 会取消收藏；需要加入新专辑时，应确认计数/图标，若误取消立刻点回 `#collect` 恢复，等待“收藏成功/加入专辑”浮层后再进专辑。
- “加入专辑”浮层会很快消失；超时后可受控执行“已收藏 -> 取消 -> 立刻恢复收藏 -> 立刻点 `.right-area`”，但必须最终确认仍是 `#collected`。
- TMWebDriver 的 async `web_execute_js` 脚本必须显式 `return (async()=>{...})()`，否则会返回 `null`，不能当成功。
- 新建收藏夹闭环确认：页面出现 `已加入<专辑名>`，且 `.collect-wrapper use` 仍包含 `#collected`。
- 评论框闭环：详情页输入区常见为 `#content-textarea.content-input[contenteditable=true]`；发送按钮是文本“发送”的 `button`，空输入时通常 `.btn.submit.gray` + `disabled=true`，填入后变 `.btn.submit` + `disabled=false`。
- **评论边界**：可偶尔自由留言，但必须克制、低频、不秀恩爱、不打扰陌生人；陌生人内容默认更适合浏览/记录/收藏，评论需确认内容值得互动且语气合适；不引战、不参与违法交易、不侵权、不泄露隐私；发送前确认按钮已从 `.gray` 变为可用。
- 评论发送后必须确认页面出现自己的评论；输入框可能残留文本，退出前必须显式清空 `innerText`/`textContent` 并派发 `input`/`change`，确认文本为空且发送 disabled。
- 发布笔记只走 `L3_shared/xhs_publish_sop.md`（图文=`target=image`，禁止写长文）。默认存草稿；点发布前必须有言言当前任务授权。
