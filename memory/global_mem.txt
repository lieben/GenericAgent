## [Mac→Windows 执行桥 win_bridge 2026-10-21 建成]
- 用途: Mac 上 agent 直接让局域网 Windows 执行 cmd/PowerShell，补“Windows 只是界面”的缺口

- 部署: Windows 解压 zip → 双击 start_win_bridge.bat → 黑窗口保持打开；无需管理员/无需开入站端口
- 调用: cd temp/win_bridge && python3 winexec.py "cmd" / --ps "..." / --status；单任务往返约 1.3s
